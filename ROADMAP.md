# Development roadmap

## Stage 1: Working foundation

- [x] Professional responsive interface and all major navigation destinations.
- [x] 30-team directory with truthful research states.
- [x] Dallas and Denver team dashboards with dated official roster snapshots.
- [x] Provisional, explained competitive timeline assessments for the two pilot teams.
- [x] Searchable pilot player database.
- [x] Local persistent GM notes, separated from sourced facts.
- [x] Source and reliability display.
- [x] Optional team-specific AI GM route with explicit configuration state and bounded usage.

## Stage 2: Reliable basketball data

1. Add a licensed or otherwise permitted data provider for live roster, standings, and player stats. Store source, retrieval time, and validation status per field.
2. Add independently verified contracts, cap status, and draft-pick ownership, including protections and swaps. Show unavailable values until checked.
3. Replace manual Dallas and Denver snapshots with a refresh pipeline, then expand the same standard to all 30 teams.
4. Build player value, team identity, and roster-needs models with explainable inputs. Validate against known cases.

## Stage 3: Decision tools

1. Configurable recommendation weights and side-by-side strategy comparison.
2. Draft strategy with verified picks and prospect data.
3. Trade simulator that separately reports CBA legality, basketball fit for each team, and likelihood.

## Stage 4: Matchup intelligence

1. Conference standings and opponent style profiles.
2. Playoff-path scenarios and skill-archetype analysis.
3. Scenario modeling with uncertainty and no small-sample overreaction.

## Stage 5: Human GM integration

1. Compare original AI recommendation, user perspective, and revised recommendation.
2. Preserve decision history and compare forecasts with actual outcomes.
3. Add sign-in and cloud storage only when the local prototype is ready for multi-device use.

## Operating principle

Each stage ships a usable slice. A blank or unavailable field is better than an invented contract, pick, stat, or trade rule.
